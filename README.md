# GitHub-for-Beginners
GitHub for Beginners is a small project to teach other student programmers the basics of GitHub. From how to use push and pull requests to recommended learning resources to dig deeper into git.

GitHub for Beginners will be used to help other beginner programmers about how GitHub works and how it can be used to record, update, share, and collaborate on projects with other people. This project hopes to open newer programmers to a community that will encourage their interest in coding.
